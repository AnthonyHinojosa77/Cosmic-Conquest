# Fonts

Latin subsets downloaded from Google Fonts (2026-09-30) and served from the game
so pages don't wait on Google's servers. All are free to redistribute:

- `bangers.woff2`: Bangers by Vernon Adams, SIL Open Font License 1.1
- `permanent-marker.woff2`: Permanent Marker by Font Diner, Apache License 2.0
- `space-grotesk.woff2`: Space Grotesk (variable, 300–700) by Florian Karsten, SIL Open Font License 1.1

Browsers cache these for a year (see `vercel.json`); if a file ever changes,
give it a new name.
